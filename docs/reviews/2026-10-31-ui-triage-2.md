# UI triage round 2 (2026-10-31)

Builds on 2026-10-30-ui-triage.md (principles still apply). Extra rules for every UI change:
- **unslop.** Read `V:/tmp/unslop/skills/unslop/SKILL.md` + `references/signs.md` before UI work.
- **No text separators.** `·`, `|`, `—` used to glue metadata together is a smell: use layout
  (columns, chips, label/value rows, icons). Remove where it isn't plain prose.
- **No layout shift.** Toggling an option must not move the control the user just clicked.
- **Alignment is a check.** Buttons/segments/headers in one row share height and baseline;
  section header actions are vertically centred. Every theme (incl. Windows 2000) must restyle
  every element: no hard-coded colours/borders/radii outside theme tokens.
- Screenshot dark + light + Windows 2000 for every UI change.
